## Quick steps

1. Do a fast scan: what’s the *one* thing that makes this feel annoying?
2. Set a timer for **6 minutes** (stop when it rings).
3. Finish with a “reset” action so it stays easy next time.

## Make it easier with automation

- If you use a smart speaker/display: add a short reminder tied to a routine (morning, after dinner, before bed).
- If you have smart plugs/sensors: automate the *cue* (reminders/notifications) rather than the whole chore first.
- If you have a robot vacuum/mop: schedule it on your busiest days.

## Done definition

- You don’t need perfection — just “good enough to feel lighter.”
